# Soluções do beecrowd

Coleção de exercícios que resolvi em C++ e Python para praticar lógica de programação, algoritmos e estruturas de dados. Cada arquivo é um programa independente; o número no nome corresponde ao ID do problema no [beecrowd](https://www.beecrowd.com.br/).

## Exemplos

- [1000 — Hello World!](beecrowd1000.cpp) (C++)
- [1001 — Extremamente Básico](beecrowd1001.py) (Python)

Para rodar os exemplos no PowerShell, a partir da raiz do repositório:

```powershell
g++ -std=c++17 beecrowd1000.cpp -o beecrowd1000.exe
.\beecrowd1000.exe
"2`n3" | python beecrowd1001.py
```

Para os problemas que exigem entrada, siga o formato do enunciado. Esta é uma coleção de estudo, não um registro de vereditos do juiz online.
